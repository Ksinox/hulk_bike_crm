Чтобы чат в MAX открывался сам

Один раз на компьютер — дальше кнопка «MAX» в карточке клиента будет сразу открывать переписку с ним, без поиска руками.

1

Поставьте Tampermonkey

Это бесплатное дополнение к браузеру, которое умеет запускать небольшие скрипты на сайтах. Ставится в два клика.

Открыть в Chrome Web Store
2

Установите наш скрипт

Откроется окно Tampermonkey с текстом скрипта — нажмите «Установить». Скрипт работает только на web.max.ru и умеет ровно одно: вставить номер в поиск и открыть чат.

Установить скрипт
3

Войдите в MAX и пользуйтесь

Откройте web.max.ru и войдите в свой аккаунт. Дальше из CRM жмите «MAX» у телефона клиента — вкладка MAX сама найдёт человека по номеру и откроет переписку.

Открыть web.max.ru

Почему нельзя проще. У MAX нет ссылки на чат по номеру: адрес вида web.max.ru/202811141 при прямом открытии сбрасывается на список чатов. А «нажать» что-то внутри чужого сайта прямо из CRM браузер не даёт — это его защита, иначе любой сайт мог бы хозяйничать в вашей почте. Поэтому шаги выполняет отдельный скрипт на стороне MAX. Без него всё работает как раньше: MAX откроется, номер уже в буфере обмена — вставьте его в поиск.
