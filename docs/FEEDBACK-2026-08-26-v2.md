# Правки 2.0 — список заказчика от 26.08.2026

Работаем как с первым списком: по одному пункту, проверка вживую на
preview, скриншоты «было/стало» на лендинге (блок «Правки 2.0»),
мобильный паритет, мерж в прод только после приёмки.

## Чек-лист

- [x] 1. «Поступит сегодня» = предполагаемые ПРОДЛЕНИЯ на сегодня.
      Сейчас чипс показывает сумму всех выплат клиента за всё время.
      Должен: для каждой аренды с датой возврата сегодня — сумма
      текущего тарифа на тот же период (Иванов взял на неделю за
      3 500 ₽, сегодня возврат → в чипс +3 500 ₽ как вероятное
      продление). Вернул скутер и не продлил → сумма из чипса исчезает.
- [x] 2. Ключ директора: изменение номера РАМЫ или ДВИГАТЕЛЯ у уже
      существующего скутера — только с подтверждением ключом.
- [x] 3. При возврате скутера (завершение аренды) поле «пробег» —
      обязательное.
- [ ] 4. «Загрузка парка» на дашборде — только бензиновая техника;
      электрички не влияют на неё и на общее количество. Рядом второй
      такой же чипс — загрузка электротранспорта (сколько всего,
      сколько в аренде, процент). Переиспользовать существующий
      компонент. Итог: чипс наших скутеров + чипс партнёрской техники
      (все электро — всегда партнёрские, свои электро не закупаем).
- [x] 5. Партнёрка = самостоятельное рабочее пространство (и будущий
      блок электричек): список всей партнёрской техники; добавление
      техники прямо в партнёрке с привязкой инвестора; создание
      инвестора и внутри него — всей его техники. Наружу мигрируют
      только должники: просрочка/день оплаты по партнёрской аренде
      попадает в общий дашборд с отметкой «электричка».
- [x] 6. Выплата инвестору: вручную настраиваются (1) периодичность —
      раз в неделю / раз в месяц, (2) день выплаты. Считать оплаты за
      расчётный период (с прошлой пятницы и т.п.), напоминание «сегодня
      выплата, сумма N», график выплат с галочкой «выплачено». Вкладка
      статистики с ежемесячными выплатами инвесторам.
- [x] 7. При добавлении партнёрской техники — возможность добавить
      инвестора (ФИО); скутера добавляются ЧЕРЕЗ инвестора. В карточке
      инвестора / фильтре: количество техники, размер инвестиций,
      средний ежемесячный доход (из выплат за расчётный период, с
      выбором произвольного отрезка времени) — видно в главном списке
      партнёрки.
- [x] 8. Список инвесторов: ФИО, количество техники, размер инвестиций
      (стоимость одной техники × количество его единиц), средний
      ежемесячный доход.
- [x] 9. Три сущности блока «Партнёрка»: список партнёров, список
      электротранспорта, таблица аренд. Партнёрские аренды НЕ
      пересекаются со вкладкой аренд наших скутеров — только на
      дашборде (должники, статистика) с явным разделением наше/партнёрское.
- [ ] 10. Блок «Скутеры»: полная изоляция подразделений. Вместо вкладки
      «Скутеры» — режимы: Аренда / Продажа / Выкуп / Не распределены,
      каждый со своей статистикой. Модели — общая настройка. Кнопка
      «Добавить скутер»: модель → данные → выбор режима. Современный
      UX/UI добавления.
- [ ] 11. Договор аренды ЭЛЕКТРОВЕЛОСИПЕДА: за основу действующий
      договор скутера, «скутер/мопед» → «электровелосипед», скутерные
      пункты убрать, применимые оставить.
- [ ] 12. В партнёрке — режим аренды её техники: переиспользовать
      функционал обычной аренды; статистика и в партнёрке, и в общей
      аналитике с пометкой наше / партнёрское / инвестора.
- [ ] 13. Адаптив CRM под маленькие экраны ноутбуков: часть контента
      теряется; блоки сделать скрываемыми/компактнее, некоторые
      переработать.

## Примечания

- Партнёрка работает только с электротранспортом и совмещает блок
  электричек и партнёрки (п.5, 7, 9).
- Электро = всегда партнёрская техника; свои электро не закупаем (п.4).
